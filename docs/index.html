Multi-Agent Ops Platform

AI agents that triage, research, and resolve incidents in real time

AgentOps is a multi-agent orchestration platform where specialized AI agents collaborate on incoming operational tasks, with every reasoning step, tool call, and handoff streamed live to a dashboard.

Live Demo View on GitHub Quickstart
Architecture

Three agents, one pipeline

Each incoming task flows through a LangGraph StateGraph. The triage agent classifies the incident and conditionally routes it: unclear root cause goes to the research agent first; known patterns go straight to the resolver.

Input
Task / Alert
REST POST from user or monitoring system
→
Agent 1
Triage Agent
Classifies category, priority, and next agent
→
Agent 2 (optional)
Research Agent
Calls tools, synthesizes root cause hypothesis
→
Agent 3
Resolver Agent
Produces ordered action plan with confidence score

Every agent step is written to Postgres and broadcast on a Redis pub/sub channel, powering live SSE streaming to the dashboard.

Features

What it demonstrates

Each feature is directly demoable and maps to a real interview question domain.

LG

LangGraph Orchestration

A typed StateGraph with conditional edges routes tasks between agents. State is passed immutably between nodes; the graph is compiled once and reused per request.

CB

Circuit Breaker

Each tool call is wrapped in a circuit breaker (CLOSED / OPEN / HALF_OPEN). After 3 consecutive failures the circuit trips open and a fallback response is returned. After a configurable timeout, a probe is sent and the circuit closes on success.

RT

Live Trace Streaming

Every agent event is published to a Redis channel and forwarded to the browser via Server-Sent Events. The dashboard shows agent reasoning, tool calls, and latency updating in real time.

DB

Full Audit Log

Every agent decision, tool call, and handoff is persisted to Postgres via SQLAlchemy async. The schema includes task_id, agent_name, event_type, JSON payload, and latency_ms on every row.

OB

Prometheus + OpenTelemetry

Five custom Prometheus metrics: agent steps/sec, per-agent latency histogram (p50/p95/p99), task outcomes, tool call results, and circuit breaker trips. OTel traces exported via OTLP gRPC.

EV

Eval Harness

A 20-task evaluation suite measures category classification accuracy and agent routing accuracy. Runs without a live LLM in CI. Analogous to RAGAS-style agent evals.

K8

Kubernetes + HPA

Kubernetes manifests with health probes, resource limits, and a HorizontalPodAutoscaler scaling from 2 to 10 API replicas on CPU (60%) and memory (70%) utilization.

CI

GitHub Actions CI

Three jobs on every push: Python tests (pytest with mocked LLM and in-memory SQLite), TypeScript type check and Vite production build, and Ruff lint.

Quickstart

Run it locally

Docker Compose starts the entire stack in one command.

bash 
# Clone and configure
git clone https://github.com/apatha32/AgentOps.git
cd AgentOps
cp .env.example .env
# Edit .env and set OPENAI_API_KEY=sk-...

# Start the full stack
docker compose up --build

# Dashboard     ->  http://localhost:3000
# API docs      ->  http://localhost:8000/docs
# Prometheus    ->  http://localhost:9090
# Grafana       ->  http://localhost:3001  (admin / agentops)

# Run the eval harness (no Docker needed)
python -m evals.harness --output results.json
